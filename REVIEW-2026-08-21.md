**Top code findings (new, on the current 1014D build):**

1. **`uint16` wrap class** (imported pecostm32 code assumes `int16` fields; this tree keeps Atlan4 `uint16`): `traceposition` wraps on rotary-down at the bottom with fast move speed — trace jumps bottom→top (`sm_1014d.c:1571`, high); time-cursor positions wrap the same way (`sm_1014d.c:292/309`, medium). 6. **F25 restore is `#if PORT_1014D`-guarded** — the 1013D variant keeps the sawtooth regression its own upstream never had (`fpga_control.c:631`).
7. Smaller: 1014D `get_fattime` returns 0 (invalid FAT timestamps on every save), unguarded RTC repaint block reachable via restored config, X-Y mode negative-index reads, capture-geometry numbers off 2× (per-ADC vs interleaved) in FPGA_NOTES/ROADMAP/analyzer, acqprobe reads CH1 unconditionally while the analyzer divides by enabled channels.
