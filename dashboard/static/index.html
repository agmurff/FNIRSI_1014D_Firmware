Control this scope from Claude

This page's /mcp path is a live MCP endpoint proxied to the instrument. Add it to Claude Code with:

claude mcp add --transport http fnirsi <url>/mcp

⚠ No authentication: anyone with this URL can view and control the oscilloscope. The tunnel address changes each time the tunnel restarts.
